# Claude Code Context

This repository contains a remote-execution capability for Kaggle.

Whenever the user asks to run a Jupyter notebook on Kaggle, or needs heavy GPU/TPU compute, you have access to the `/kaggle-run` skill.

**Skill**: `kaggle-run`
**Usage**: Automatically push, execute, and download results from Kaggle Notebooks using the `kaggle_runner/run.py` script.

See `.agents/skills/kaggle-run.md` for full instructions.
